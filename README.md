# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

灯种称呼必须以「前缀簿」中任一合法前缀**开头**，否则当场拒收（不入队），拒收样例当日可见。前缀簿由校准员增删，每次变更写入履历；删除前缀不会改写已入队旧单的原称呼。巡检员可查看前缀簿、当日拒收与履历，但不可增删。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 顶栏进入「前缀簿」：初始簿中只留「氦」，履历有一条初始记录。
5. 簿里只有「氦」时，投「氦灯零一」应收（入队），投「汞灯零九」应拒收，拒收出现在「当日拒收样例」。
6. 删除前缀「氦」后再投「氦灯零一」应拒收；此前的旧氦灯单仍保留原称呼不变。
7. inspector 打开前缀簿只能查看，无新增/删除入口；直接调写接口返回 403。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/prefixes` | 登录 | 当前合法前缀 |
| POST | `/api/prefixes` | writer | 新增前缀，写履历 |
| POST | `/api/prefixes/delete` | writer | 删除前缀，写履历；旧单不改写 |
| GET | `/api/prefixes/audit` | 登录 | 变更履历 |
| GET | `/api/rejected` | 登录 | 当日拒收样例 |
| POST | `/api/jobs` | writer | 称呼不匹配任一前缀时 400 拒收 |
